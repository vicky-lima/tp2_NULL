Para correr el archivo TP-02_NULL.py es necesario tener instaladas las librerias:
- duckdb

Para que el codigo funcione hay que correr las celdas de los import y la lectura de los archivos primero.
El código esta separado en celdas por incisos, a excepción de algunos graficos. Es por esto que 
para su correcto funcionamiento hay que correr las celdas en el orden en que están, ya que utilizamos 
particiones de los archivos generadas con Pandas.
